# y230028-----keyboard
Keyball44    トラックボール付き４０％左右分割キーボードキット

Keyball44 は、Yowkees によって開発された左右分割型の自作キーボードであり、親指操作型のトラックボールを搭載している点が特徴である。通常のキーボードとマウスを別々に使用する必要がなく、キーボード上でカーソル操作を行えるため、作業効率の向上やデスクスペースの節約に役立つ。また、トラックボールを親指で操作できる構造となっており、直感的なカーソル操作が可能である。

Keyball44 は 44 キー構成を採用しており、コンパクトな設計でありながら、レイヤー機能を利用することで多様な入力操作を実現している。さらに、左右分割型のエルゴノミクス設計により、自然な手首の角度を維持しながらタイピングできるため、肩や手首への負担軽減が期待される。このような特徴から、長時間の作業やプログラミング用途に適したキーボードとして評価されている。

組み立てにははんだ付け作業が必要であり、自作キーボードとしては比較的高度な部類に入る。必要部品には、ProMicro マイコン、Cherry MX 互換キースイッチ、34mm トラックボール、TRS ケーブルなどが含まれる。また、OLED モジュールや RGB LED（SK6812MINI-E）にも対応しており、視認性や装飾性を高めることが可能である。

ソフトウェア面では、ファームウェアとして QMK を採用し、VIA に対応している。そのため、ユーザーはキー配置やショートカット機能を自由に変更でき、専用ソフトウェア上でリアルタイムにキー設定を変更することが可能である。この高いカスタマイズ性により、利用者の用途や作業環境に合わせた柔軟な設定が実現できる。

接続情報としては、ベンダーIDが「0x5957」、製品IDが「0x0400」、VIAプロトコルバージョンが「0x000C」であり、キーマトリクスは「6列×8行」の構成となっている。登録ステータスは「承認済み」であり、VIA 上で正常に認識されることが確認されている。さらに、GitHub 上では継続的な改良が行われており、OLED 表示機能やマウスレイヤー機能の追加など、機能拡張も進められている。
